# Tasks
# Python Fundamentals to MLOps — Complete Learning Path

## Course Structure (60 Parts)

### Python Fundamentals (Parts 1–5)
- **Part 1:** Variables, types, operators, type conversion, try/except
- **Part 2:** if/else, loops (while/for), functions, lambdas, return values
- **Part 3:** Strings, lists, tuples, dicts, indexing, slicing, comprehensions
- **Part 4:** Classes, objects, __init__, methods, dunder methods, decorators, inheritance
- **Part 5:** File I/O, with statement, exception handling, finally, generators, yield, JSON

### Data Processing (Parts 6–10)
- **Part 6:** NumPy arrays, vectorization, broadcasting, reshaping, slicing, dtypes
- **Part 7:** NumPy math functions, aggregations, linear algebra basics, sorting
- **Part 8:** Pandas Series, DataFrames, reading CSV/JSON, basic indexing, selecting data
- **Part 9:** Pandas filtering, querying, data cleaning (missing values, duplicates, types)
- **Part 10:** Pandas transformation, groupby, aggregation, pivot tables, merging

### Databases & APIs (Parts 11–16)
- **Part 11:** SQL basics, CREATE/INSERT/SELECT, WHERE, ORDER BY, LIMIT, aggregate functions
- **Part 12:** SQL JOINs (INNER/LEFT/RIGHT/FULL), GROUP BY, HAVING, subqueries
- **Part 13:** SQL transactions, ACID, indexes, views, ALTER TABLE, advanced queries
- **Part 14:** Database design, normalization, relationships, constraints, foreign keys
- **Part 15:** APIs, requests library, JSON parsing, status codes, headers, authentication
- **Part 16:** Web scraping basics, BeautifulSoup, parsing HTML, CSS selectors, storing data

### Data Visualization (Parts 17–19)
- **Part 17:** Matplotlib basics, line plots, bar charts, scatter plots, styling
- **Part 18:** Matplotlib advanced, histograms, box plots, subplots, multiple datasets
- **Part 19:** Seaborn, relational plots, categorical plots, heatmaps, distribution plots

### Mathematics for AI (Parts 20–23)
- **Part 20:** Probability basics, events, rules, conditional probability, Bayes' theorem
- **Part 21:** Probability distributions, binomial, uniform, normal, central limit theorem
- **Part 22:** Linear algebra basics, vectors, matrices, operations, determinants, eigenvalues
- **Part 23:** Calculus basics, functions, derivatives, differentiation rules, minima/maxima

### Machine Learning (Parts 24–36)
- **Part 24:** Supervised learning intro, regression vs classification, train/test split
- **Part 25:** Linear regression, best fit line, cost function, gradient descent, evaluation
- **Part 26:** Feature engineering, encoding, dummy variables, scaling, normalization
- **Part 27:** Logistic regression, sigmoid, decision boundary, classification metrics
- **Part 28:** Naive Bayes, kNN, confusion matrix, precision, recall, F1, cross-validation
- **Part 29:** Decision trees, entropy, gini impurity, information gain, pruning
- **Part 30:** Random forest, bagging, boosting, XGBoost, hyperparameter tuning
- **Part 31:** Model evaluation, ROC-AUC, PR-AUC, calibration, overfitting/underfitting
- **Part 32:** SVM, maximum margin, kernels, C and gamma hyperparameters
- **Part 33:** Ensemble methods, voting, stacking, blending, model selection
- **Part 34:** Unsupervised learning, clustering, K-means, elbow method, silhouette score
- **Part 35:** Hierarchical clustering, DBSCAN, dimensionality reduction, PCA
- **Part 36:** Anomaly detection, isolation forest, LOF, local outlier factor

### Deep Learning (Parts 37–50)
- **Part 37:** Deep learning basics, neural networks, perceptron, forward propagation
- **Part 38:** Backpropagation, chain rule, loss functions, weight updates, optimizers
- **Part 39:** PyTorch basics, tensors, autograd, DataLoader, custom datasets
- **Part 40:** Building neural networks, nn.Module, training loops, evaluation
- **Part 41:** CNN architecture, convolution, pooling, ResNet, transfer learning
- **Part 42:** Image classification project, augmentation, fine-tuning, Grad-CAM
- **Part 43:** RNN, LSTM, GRU, sequence modeling, time series, NLP preprocessing
- **Part 44:** Text processing, tokenization, embeddings, TF-IDF, word vectors
- **Part 45:** Sentiment analysis project, text classification, model deployment
- **Part 46:** Transformers, attention mechanism, self-attention, multi-head attention
- **Part 47:** BERT, GPT, T5, pre-trained models, fine-tuning with HuggingFace
- **Part 48:** RAG basics, document ingestion, vector stores, retrieval, generation
- **Part 49:** LangChain, LCEL, chains, retrievers, memory,
